# media/src — 書き出し前の元素材

サイトからは参照されない。**切り出し直しが必要になったときのための原本置き場**。

## resident-avatars-source.png

「修練医の声」（`recruit.html` #residents）のアバター3枚の元絵。1536×1024、背景透過のRGBA。
3人が横に並んでおり、人物と人物の間は完全な透過（alpha=0）で区切られている。

パネルの境界（透過列の実測値）:

| パネル | x範囲 | 幅 |
|---|---|---|
| 1（左・黒スクラブ） | 0–498 | 499 |
| 2（中央・長髪） | 510–1023 | 514 |
| 3（右・黒縮毛） | 1036–1535 | 500 |

書き出し済みファイルは `media/resident-avatar-{1,2,3}.png`（各256×256、透過のまま）。
切り出しに使ったパラメータは以下のとおり（パネル内座標。`center_x` は頭部の中心、
`top` は切り出し正方形の上端、`side` は一辺）:

| 出力 | center_x | top | side |
|---|---|---|---|
| resident-avatar-1.png | 249 | 45 | 575 |
| resident-avatar-2.png | 244 | 128 | 528 |
| resident-avatar-3.png | 238 | 30 | 605 |

`side` は人物ごとの頭の大きさに合わせて変えてある（3枚を並べたときに顔の大きさが
揃って見えるようにするため）。切り出し手順は、**パネルを1枚ずつ切り出してから**
正方形を取ること。元画像のまま正方形を取ると、隣のパネルの人物が写り込む。
